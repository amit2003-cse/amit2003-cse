## 🚀 Featured Engineering Projects

### [🧠 ReviseFlow: Algorithmic Spaced Repetition Engine](#) *(Next.js 15, React 19, MongoDB, Prisma)*
*A guilt-free Spaced Repetition architecture and Deep Work environment designed to conquer the Ebbinghaus Forgetting Curve.*
- **Algorithmic Scheduling Engine:** Architected a background engine that dynamically calculates optimal neurological retrieval intervals (Fibonacci-like scale) for long-term memory retention.
- **Zero-Guilt UX Flow:** Abstracted absolute scheduling complexity; engineered a system that safely queues overdue topics into a chronological "Today's Revision" list rather than breaking user streaks, minimizing cognitive friction.
- **Deep-Work Integration:** Engineered a native Pomodoro timer utilizing the Web Audio API with strict focus/break loops and rotating philosophical grounding to prevent doom-scrolling.
- **Secure Architecture:** Implemented Role-Based Access Control (RBAC) via Google OAuth & NextAuth, protecting a concealed admin analytical dashboard. Built utilizing Next.js Server Actions & API Routes natively executing in Node.

### [📊 FinAssessPro: Advanced Borrower Risk Assessment System](#) *(React/Vite, Node.js, Express, MongoDB)*
*A comprehensive financial assessment intelligence platform evaluating borrower eligibility and risk parameters.*
- **Dynamic BI Score Engine:** Engineered an intelligent scoring algorithm evaluating multi-dimensional risk parameters (Age, Income, CIBIL, Bounce rates, Net Worth) to categorize applicants into actionable Risk Bands (0-100 scale).
- **Secure Backend Design:** Hardened the API architecture with Express Rate Limiter, Mongo Sanitize, and XSS Clean middlewares to mitigate DDoS and injection vulnerabilities.
- **Automated Workflows:** Integrated Resend API for real-time asynchronous evaluation reports upon multi-step form completion. Managed modular frontend state using Zustand and enforced robust schema validation via Zod.

### [🤖 AI Teaching Assistant: RAG-Based Tutor](https://github.com/amit2003-cse/ai-virtual-teaching-assistant) *(Python, Local LLMs, Qdrant)*
*An intelligent context-aware tutoring platform tailored for efficient student workflows.*
- **RAG Architecture:** Designed a Retrieval-Augmented Generation pipeline leveraging a customized knowledge base with **Qdrant Vector Database**.
- **Resource Optimization:** Optimized context chunking and retrieval to run performantly alongside local LLMs (Ollama) targeted specifically at low-resource machines with offline capabilities.

### [🟡 Mom's Kitchen](https://moms-handmade.netlify.app/) *(MERN Stack)*
